|---|---|

| 02 Diner Menu & Brand Site | Diner: Menu, Dish sheet, Cart, Order tracking, Invalid QR · Web: Home |

Pages 02 and 03 are generated by the local plugin in `figma-plugin/` from the page 01 components and variables, so the screens stay linked to the design system. (The Figma MCP Starter-plan limit blocks building them remotely.)

## Build the screens (one-time, ~30 seconds)

1. Open the Figma **desktop app** and open the TableOS file.
2. Menu → **Plugins → Development → Import plugin from manifest…** and pick `design/figma-plugin/manifest.json`.
3. Menu → **Plugins → Development → TableOS Screens**.

It loads the real dish photos, places every screen, and reports any issue in the toast when done. Re-running replaces only the screens it created. The CSS tokens in `packages/ui/src/styles/tokens.css` mirror the Figma variables.
